## Decisions

- Java is the reference implementation; a decoder disparity is resolved by changing the Rust port (Eric, 2026-10-06).
- A struct-level serde default rather than a special case for empty bytes in `from_bytes`: it is the Java rule for every missing
  key, not only for the empty map (my call, for Eric's review).
