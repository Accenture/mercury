## Summary

The Java engine merged mercury-composable #586 (squash `356b5190`). Its command service sends every refusal with an error
status, and its synchronous companion endpoint reads that flag instead of a list of error words. Eric asked for the port; the
Java repository's thread `companion-refusal-flag-rust-twin` tracks it.

What was built (branch `feat/companion-refusal-flag`, from `main` at `c2aa9c28`):
- **`commands.rs`:**
  - `refuse()` sends a refusal with status 400 (`REFUSED`), and 35 call sites use it. `refuse_value()` relays a skill's error
    from `execute` with the skill's own status.
  - The pre-run gate's abort, which already set 400 by hand, goes through `refuse()`.
  - The import fallback's "Graph model not found in" line is a refusal only when no deployed copy follows.
  - `import node` from a file that does not exist, and `session` with an unknown argument, now refuse instead of printing nothing.
  - Java has 36 call sites; its extra one is the write-failure line, which this engine prints through `handle`'s own `ERROR:`,
    a refusal too.
- **`rest.rs`:**
  - `CaptureSink` records the first line with `has_error()` and tees each line with its status. It already received the whole
    envelope, so it needed no change of shape, unlike Java's capture lambda, which became a class.
  - The topology refusal's line carries the status.
  - The endpoint's error is the first flagged line, else the dispatch RPC's own failure, else a truncated capture.
  - `is_error_line` and `first_error_line` are removed.
- **Tests:** three plain `async fn`s on the one booted server in `tests/playground.rs`, with a `sync_command` helper:
  - `create_on_an_existing_node_is_a_failure`;
  - `help_prose_is_never_a_failure`, over every page under `resources/help`;
  - `every_refusal_is_a_failure_whatever_its_wording`, which also covers `{not json}` and the refused export.
- **Docs:**

    `ok` is the engine's own verdict, with no engine qualifier: both engines now flag.
  - `command-reference.md` gains Java's bullet for a create on an existing name.
  - A new claim, `companion-ok-is-the-engine-verdict`.
