## Lessons

- The zero-traced/skip-list semantics had drifted from Java (this port zero-traced the whole route) and
  nothing noticed for months because the RPC path folds the record anyway; the stream relay's callback
  execution was the first consumer of the difference.
- A stream's head and tail are the only segments worth a span; the terminal record carries the count.
