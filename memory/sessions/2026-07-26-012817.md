## Semantics edge cases hit

1. **Whole-file atomicity**: Java's parse throws mid-file and the catch
   discards the file's partial map — a shape error ANYWHERE in a file skips
   the entire file, not just the bad entry. Mirrored via Result over the
   whole parse.
2. **First-wins instances is fill-if-unset**, not first-file-wins outright:
   file1 unset + file2 sets 9 → 9; file1 sets 5 + file2 sets 9 → 5
   (Java `if (prior.instances == -1)`).
3. **The log's [original] is the DECLARED route string** (Java svc.route() —
   possibly comma-separated), not the matched original key.
4. **Route-list rendering**: Java prints List.toString ([a, b]); Rust's
   `{:?}` would add quotes — joined manually for presentation parity.
5. **Boot needs a #[main_application]** in the test binary (lifecycle
   completes) — same pattern as annotations.rs.
