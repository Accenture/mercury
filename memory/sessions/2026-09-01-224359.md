## Durable lessons

- **crates.io throttles NEW crate names** (~5 burst, then ~1 per 10 min): plan a
  multi-crate first publication in waves; version updates to existing crates are not
  affected.
- **cargo 1.95 `publish --workspace` does not resume**: rerunning after a partial
  publish fails with "crate X already exists"; finish stragglers with
  `cargo publish -p <crate>` individually.
- **Create the GitHub release BEFORE `git checkout v4.12.1`:** with no tag minted,
  checkout silently used a local BRANCH of that name ("Switched to branch", not
  "detached HEAD") — same commit here so harmless, but a name that shadows a future tag;
  branch deleted, real tag minted after.
- A crate-local README beats the workspace `readme` pointer (cargo warns, ships the
  local copy — the right outcome for minigraph-state-redis; pointer fix queued).
