## Lessons
- **Audit manifest metadata before a crate's first publish** — keywords (≤ 5, each ≤ 20 chars), categories, readme path: cargo
  does not validate them and crates.io rejects at upload, after the ordered run has published everything before the failing
  crate. A ten-line audit script (in the scratchpad) would have caught it; recorded on [[conv-template-version-sweep-rust]].
- **Name the service the reviewer will look under BEFORE the drive** — agree it (or pass it explicitly) with the
  endpoint and the token; the first report pointed the UI check at the example's default service name.

- **`${ENV}` references are resolved ONCE, when the base configuration loads** (`ConfigReader::new_base`
  → `resolve_references`; an unresolvable lone reference drops the key, so `get_property` reads `None`).
  The suite's first late-credential scenario set an env var after boot and got nothing — the live path is a
  runtime override (`overrides::set`, the `-D`/`System.setProperty` analog, consulted first on every
  lookup), which is also the true twin of Java's vault-published system property. Recorded in the guide,
  the README and the new fact.
- **Annotated functions are constructed BEFORE the `before_application` hooks run** (the lifecycle
  collects every inventory entry's factory first), so a hook cannot pre-install state for a preload's
  `Default` — the forwarder resolves its exporter on the first dataset (`OnceLock`). The tell was a doubled
  "credential header resolved" line: two suppliers, two exporters.
- **Marker attributes are matched by single-segment ident** (`is_ident("zero_tracing")`): written bare and
  below the primary attribute they are consumed before name resolution and need NO import; a path-qualified
  `#[platform_core::optional_service(...)]` is not recognized, survives, and then fails as a macro of its own.
- **A drive must assert the port hand-off.** The first drive stopped each leg with SIGTERM and waited one
  second; the graceful shutdown takes longer, so legs B/A′ hit leg A's process (real token, 0 failures) while
  their own processes died on `Unable to bind port 8100` — "datasets logged: 0" was the tell. The redriven
  script waits for the listener pid to change and hard-kills after 10 s (the Redis outage-drive lesson again).
- clippy `err_expect` wants `expect_err`, which needs `Debug` on the Ok type — a `let Err(e) = ... else`
  when the Ok type is not `Debug`; rustfmt splits `.err().expect(` across lines, so a whitespace-tolerant
  regex is needed to fix all sites.
