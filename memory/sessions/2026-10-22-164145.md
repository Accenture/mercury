## Summary

This is the Rust half of RFC-0010's WP4. Increment 185 (#391, merged 2026-10-22) refused a JSONPath outside RFC 9535 and
checked that this engine already substitutes before it parses. WP4 adds the RFC's safeguard, so that a substituted value cannot
change the query's structure.

Eric's two rulings, recorded in the RFC:
- **Event Script keeps a text value bare in a filter as written when it is already one literal** (`10`, `true`, `'abc'`), so
  numeric text still compares as a number. The knowledge graph quotes all text.
- **A name takes Mercury's dot-bracket key path** (`items[0].name`).

What was built (branch `feat/jsonpath-substitution-rfc-0010`, from `main` after #391):
- **`jsonpath_source::substitute`**, which renders each value by its site, refuses a list or a map, and keeps `[model.i]`'s
  `str2int` and `string_from_model_value`'s rendering.
- **`mapping::has_json_path` and `substitute_json_paths`**, with `argument_spans` behind the splitter.
- **The callers:**
  - `executor::substitute_dynamic_index` (its former body is now `substitute_references`);
  - `common::substitute_mapping_source`.
- **The backslash fix** in `append_parameter`: the backslash is escaped first, then the quote, because the `graph.math` lexer
  reads `\\` as an escape, exactly as Java's does.
- **The tests:**
  - the shared vectors: 35 sources, 39 substitutions, 11 argument splits and 5 reference keys, byte-identical with Java and all
    passing on their first run;
  - the flow `json-path-substitution-test`, in `flows_run_end_to_end_like_java`;
  - the graph `unit-test-jsonpath-2`, in `graph_runtime_end_to_end`, with 67 compiled graphs.
